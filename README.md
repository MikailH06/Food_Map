# Food Map

## Overview
The Food Map project started from a personal interest in exploring restaurants throughout the Los Angeles area. I originally kept a simple list of restaurants I wanted to visit, but as the list grew, I found it increasingly difficult to remember what each restaurant offered and where they were located.

Rather than creating a more detailed list, I decided to turn the problem into a software project and use my programming and web development skills to build a solution. With the assistance of AI tools, I developed a full-stack web application that provides an interactive map of restaurants and allows users to store additional information such as cuisine type, average price, reviews, and images.

The project gave me a more useful way to organize and explore restaurants while also serving as an opportunity to strengthen my skills in frontend and backend development, database management, API integration, and application architecture.

## Features
- Interactive restaurant map
- Restaurant pins and locations
- Cuisine/food type
- Average price
- Reviews
- Restaurant images
